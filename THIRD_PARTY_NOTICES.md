This package includes fixed gene-set files so that pathway results can be
reproduced without retrieving a later library version. These files are not
relicensed by the project licences.

- Retrieval interface: Enrichr gene-set library API
- Upstream resource: Molecular Signatures Database (MSigDB), Hallmark collection
- Terms: MSigDB licence terms, <https://www.gsea-msigdb.org/gsea/msigdb_license_terms.jsp>
- Citation: Liberzon A, Birger C, Thorvaldsdóttir H, Ghandi M, Mesirov JP,
  Tamayo P. The Molecular Signatures Database Hallmark Gene Set Collection.
  *Cell Systems*. 2015;1(6):417-425. <https://doi.org/10.1016/j.cels.2015.12.004>

Users remain responsible for confirming that their intended reuse complies
with the MSigDB terms and any terms applicable to the underlying collection.
